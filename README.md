# teleport-app-coder-test

Date: 2026-06-08

## Baseline Probe

This repository is a test and demonstration sandbox for the Teleport AI coding
agent. Its purpose is to serve as a minimal, low-risk environment where the
autonomous agent can be exercised end to end — receiving prompts, making changes
to files such as this `README.md`, and recording those changes in
[`AI_CHANGES.md`](AI_CHANGES.md).

It is not a production application. Rather, it acts as a baseline probe:
a simple, known starting point used to verify that the agent can read the
existing structure of a repository, apply requested modifications, and leave a
clear trail of its work.
